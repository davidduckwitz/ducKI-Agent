## Zweck
Planungs-Modus: erzeugt einen strukturierten Plan (Ziel, Schritte, Komplexitaet)
ueber den Planner, ohne irgendeinen Schritt oder ein anderes Tool auszufuehren.
Nutze dieses Tool, wenn der Nutzer explizit einen Plan/Ueberblick anfordert,
bevor tatsaechlich gearbeitet wird, oder wenn eine Aufgabe komplex genug ist,
um sie zuerst zu skizzieren.

## Core-Tool
Dieses Tool ist als Core markiert und kann in den Settings nicht deaktiviert
werden - Planungsanfragen duerfen nie an fehlende Tool-Freischaltung scheitern.
