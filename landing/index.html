In 1 Minute installiert

Ein Befehl — der Installer erledigt Voraussetzungen, Clone und Build automatisch

🍎🐧

macOS · Linux · WSL · Raspberry Pi

In ein Terminal einfügen:

curl -fsSL https://ducki-ai-agent.davidduckwitz.de/install/install.sh | bash

Update: ./install/update.sh

🪟

Windows (PowerShell)

In eine PowerShell einfügen:

irm https://ducki-ai-agent.davidduckwitz.de/install/install.ps1 | iex

Update: .\install\update.ps1

Der Installer übernimmt in 3 Schritten:

  1. 1. Voraussetzungen prüfen & installieren (git, Node ≥ 20, pnpm ≥ 9)
  2. 2. Repository klonen (oder per git pull aktualisieren) & bauen
  3. 3. Start mit pnpm dev — Web UI auf http://localhost:3000
