🚀 Quickstart

Starten Sie in 3 Minuten:

1

Clone Repository

git clone https://github.com/davidduckwitz/ducKI-Agent
2

Install Dependencies

cd ducKI-Agent && pnpm install
3

Configure & Start

cp .env.example .env && pnpm run dev

⚙️ Setup Hinweise

  • → Settings (Einstellungen): Stellen Sie in /settings zuerst Ihren LLM-Provider und Modell ein (z.B. LM Studio, OpenRouter, OpenAI)
  • → Skills aktivieren: In /skills können Sie nur benötigte Skills aktivieren
  • → Chat starten: Benutzen Sie /chat für interaktive Arbeit
  • → Workflows: Nutzen Sie /workflow für komplexe Multi-Agent Läufe
  • → Überwachen: Verfolgen Sie aktive Agent-Läufe in /agents

❓ Häufig gestellte Fragen

Kann ich DucKI kostenlos verwenden?

Ja, DucKI Agent ist kostenlos und Open Source. Sie können es lokal installieren und verwenden.

Funktioniert DucKI vollständig offline?

Ja, mit LM Studio können Sie DucKI vollständig offline betreiben. Wenn Sie externe LLM-Provider nutzen, benötigen Sie einen Internet-Zugang.

Auf welchen Systemen läuft DucKI?

DucKI läuft auf Linux, macOS und Windows. Voraussetzung ist Node.js 16+.

Wie kann ich Tools oder Skills hinzufügen?

Sie können neue Tools und Skills als Plugins erstellen oder über Pull Requests zum Projekt beitragen.
