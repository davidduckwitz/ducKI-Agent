Installation & Update

Ein Befehl — alles Weitere übernimmt das Skript: Voraussetzungen, Clone, Build, Autostart.

🚀 1-Klick-Installation

In ein Terminal einfügen:

curl -fsSL https://ducki-ai-agent.davidduckwitz.de/install/install.sh | bash

Update später: ./install/update.sh im Projektordner.

In eine PowerShell einfügen:

irm https://ducki-ai-agent.davidduckwitz.de/install/install.ps1 | iex

Update später: .\install\update.ps1 im Projektordner.

Was der Installer macht

  1. 1Prüft & installiert git, Node ≥ 20 und pnpm ≥ 9 (via NodeSource / winget / Homebrew).
  2. 2Klont das Repository — oder aktualisiert eine vorhandene Installation per git pull --ff-only.
  3. 3Führt pnpm install und pnpm build aus.
  4. 4Optional (Linux/Pi): richtet einen systemd-Autostart-Dienst ein.

📥 Skripte direkt herunterladen

install.sh (Unix/Pi)↓ install.ps1 (Windows)↓ update.sh (Unix/Pi)↓ update.ps1 (Windows)↓

Konfigurierbar über Env-Variablen: DUCKI_REPO, DUCKI_BRANCH, DUCKI_DIR, DUCKI_SERVICE=1.
